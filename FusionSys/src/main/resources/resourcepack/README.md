# FusionSys Resourcepack

Скелет ресурспака с кастомными текстурами для новых предметов и блоков FusionSys.

## Структура

```
assets/fusionsys/
  models/item/    — модели предметов (черновик, обложка, справочники, кисть, ключ, метеорит, металлография)
  models/block/   — модели блоков: магнит, стадии метеорита (stage_1/2/final), гематит
  textures/item/  — текстуры предметов (16×16 PNG)
  textures/block/ — текстуры блоков: магнит, стадии метеорита, гематит
```

ВАЖНО: текстуры стадий метеорита и гематита НЕ переопределяют ванильные блоки
(blockstate-оверрайды netherack/basalt/stone/iron_block удалены). Они применяются
ТОЛЬКО к блокам метеорита через персонализированный вид (item_model / кастомные
модели блоков, назначаемые в плагине), чтобы не менять вид обычного незера/базальта/камня в мире.

## Назначение моделей предметам

Модели лежат в отдельном неймспейсе `fusionsys:*` и НЕ переопределяют ванильные.
Привязка к конкретному предмету происходит через компонент `minecraft:item_model`
(Paper 1.21.1) на самих кастомных предметах в плагине, например:

```
/item_model = fusionsys:draft
```

Чтобы использовать ресурспак на сервере:
1. Запакуйте папку `resourcepack` в zip (`pack.mcmeta` в корне).
2. Укажите серверный хэш ресурспака в `server.properties` (resource-pack=…).
3. Установите ресурспак клиентам (вручную или через server resource pack prompt).

Пока задаются только базовые одноцветные заглушки 16×16. Для полноценных текстур
замените PNG в `textures/*` на готовые работы. Модели ссылаются на слои `layer0`
(предметы) и `all` (блоки).
